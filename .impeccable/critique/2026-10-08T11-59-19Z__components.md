## Design Specificity Verdict
LLM assessment: the app is a ChatGPT clone with a brand accent. tailwind.config.ts:12 literally says "ChatGPT-like palette", and ChatWindow.tsx:1440 says "Gemini-style start screen". The Helvetica stack, the generic starters ("Python-Skript schreiben"), the random greetings and a rainbow AI glow make it interchangeable. The product's real differentiators (the knowledge base, pipeline badges, sidekicks and assistants) sit hidden behind 36px icon toggles.
Deterministic scan: 3 findings, 1 true positive. ai-color-palette at Sidebar.tsx:457 (violet/indigo glow-and-glass New-chat button) is real. gray-on-color at FileManager.tsx:158 (hover-only bg) and side-tab at globals.css:239 (blockquote) are false positives. The detector's exit code was 0 although it reported findings. No browser overlay was possible.

## Priority Issues
- [P1] Keyboard and touch users cannot reach core actions. Message and sidebar-row actions use opacity-0 group-hover (8 sites). The codebase has 1 focus-visible and 0 role=dialog. The closed sidebar is still focusable (no inert). Settings has no Esc. Fix: group-focus-within + hover:none reveal, inert, a shared dialog hook. Command: /impeccable harden
- [P1] Contrast failures across all themes: light-mode code blocks at 1.5-2.7:1 (dark hljs palette on #f6f8fa); text-neutral-500 without a dark override (177 uses, 3.0-3.4:1); accent text on dark at 2.56:1; white on the Dracula accent at 2.41:1. Fix: a light hljs palette, a muted text token, dark-adjusted accent. Command: /impeccable colorize (tokens) then /impeccable polish
- [P1] i18n is a facade. About 20 keys and 4 files use useT. An "English" user gets roughly 95% German, and html lang stays de. Fix: hide the option or move the shell, input, message actions and Settings nav into STRINGS. Command: /impeccable clarify
- [P1] Destructive actions are inconsistent: three confirm styles, and incognito delete with no confirm or undo plays a 1.15s shatter. Fix: one ConfirmDialog on Modal, or a 5s undo toast. Command: /impeccable harden
- [P2] Generic start screen and identity: replace STARTERS with KB, assistant and sidekick entry points; bind the violet/glow to the brand accent; respect reduced motion. Command: /impeccable shape then /impeccable bolder
